# Stash Notes 宣伝動画 (22秒)

SNS 向けの 22 秒動画を [Remotion](https://www.remotion.dev/) で組んだもの。
React で書いたシーンを CLI で MP4 にレンダリングする。

> このディレクトリは **ルート `package.json` の workspaces に入れていない**。
> CI (`.github/workflows/deploy.yml`) のビルドにも本番デプロイにも一切関与しないので、
> ルートの lockfile もデプロイ時間も汚さない。

## 使い方

```bash
cd video
npm install          # 初回のみ
npm run studio       # ブラウザでプレビュー・スクラブ (http://localhost:3000)
npm run render       # 3 比率まとめて out/ に書き出し
node analyze.mjs     # 書き出した動画を分解して分析する (下記)
```

個別に出すとき:

```bash
npm run render:vertical    # 1080x1920  X / リール / TikTok / Shorts
npm run render:landscape   # 1920x1080  X タイムライン / YouTube / 埋め込み
npm run render:square      # 1080x1080  Instagram フィード
```

途中の絵を 1 枚だけ確認したいとき (frame は 0〜659):

```bash
npx remotion still StashNotes32-Vertical out/check.png --frame=300
```

## 何を伝える動画か

**想定している場面は 1 つだけ: 「ログインしたくない端末へ長文を渡したい」。**
共用 PC・借りた端末・人に送る — どれも、まずログインが要る。
Stash Notes なら URL を開くだけで済む、という 1 点に絞ってある。機能の紹介はしない。
タブ・PIN・有効期限・アクセス履歴・オフラインは意図的に一切出していない。

字幕は 5 つで **1 つの文**になっている:

> この長文を → 別の端末に送りたい → でも ここではログインしたくない → URLを開くだけ → 全部そのまま

| 時間 | 中身 | 字幕 |
| --- | --- | --- |
| 0:00 | **タイトル。**ロゴ → 下線が引かれる → タグラインが 1 行ずつ | ログインなしで / 長文を渡す |
| 0:03 | 手元のノート PC が中央に落ちてくる。光の帯が本文を走り 文字数が数え上がる | この長文を |
| 0:07.5 | URL が光る → その真下にコピーの合図 | 別の端末に送りたい |
| 0:10 | **手元の PC が左上へ縮んで残り 渡す先の PC が右から入ってくる** | ↑ |
| 0:14.5 | **example.com のログイン画面**が落ちてきて埋まっていく | ↑ |
| 0:16.5 | **右上の閉じるボタンを押して 自分で畳む** | でも ここではログインしたくない |
| 0:19.5 | **URL が notes.rou39.com に切り替わり** 原稿が 1 行ずつ届く | URLを開くだけ |
| 0:23.5 | 文字数が 2,438 に到達 光の帯が 2 回走る | 全部そのまま |
| 0:27.5 | 3 語 | 登録ナシ / アプリナシ / URLだけ |
| 0:29.8 | 締め (ボタン型の CTA) | notes.rou39.com / 無料 登録不要 |

守っている決めごと:

- **いきなり実演から始めない。**まずタイトルで名乗って「何ができるのか」を一言で置き、
  そのあとの実演がその説明になる、という順番にする。
- **実演はカットで切り替えない。**1 枚のキャンバスに描き足していく。
  中央に描いたものは**縮んで左上へ移り そのまま残る**。入れ替わりに次のものが**右から入ってくる**。
  画面が丸ごと入れ替わると「さっきの長文が あっちの端末に出た」という繋がりが切れるため。
  この動きは `src/scenes/Demo.tsx` の `lapToCorner` / `monIn` で作っている。
- **尺より伝わりやすさを優先する。**間はわざと長めに取ってある (実演だけで 25 秒)。
- **広告なので句読点 (、。) は使わない。**区切りは分かち書き (半角スペース) にする。
- **同時に出る字幕は 1 行まで。**全部で 6 行しかない。
- **視線の順路を一本道にする。同時に 2 か所を動かさない。**
  中央 → 上 → 中央を下へ → 右下、のように 1 つずつ移す。
  字幕の切り替えと画面内の変化を重ねると視線が散る (以前これで失敗した)。
  各シーン冒頭の `T` はこの順路をそのまま並べたもの。
- **1 フレーム目がサムネイルになる。**タイトルをフェードインさせず、frame 0 の時点で
  ロゴが出ている状態にする (`Scene` の `fadeIn={false}`)。
- **ロゴは左上に出しっぱなし。**最後まで見ない人が大半なので、締めだけに名前を出すと誰にも残らない。
  ただしタイトルの間だけは隠す (同じものが 2 か所にあると視線が散る)。
- **サンプルは「長い」ことが目で分かるものにする。**箇条書き数行では
  「メールで送ればいい」で終わってしまうので、打ち直す気にならない量の地の文にする。
  文字数バッジのカウントアップも同じ目的。
- **ログインは「できない」のではなく「したくない」。**ここは間違えやすい。
  中央に赤い ✕ を叩きつけたり 背景を警告色にしたりすると、どうしても
  **「ログインに失敗した」「弾かれた」**に見えてしまう。伝えたいのはそうではなく
  「ログインできるけれど この端末ではしたくない」なので、
  **ダイアログ右上の閉じるボタンを押して自分で畳む**という見せ方にしてある。
  背景にも警告色は入れない。
- **問題は「打ち直す手間」ではなく「送る手段がログインを要求すること」。**
  「この長さ 打ち直せますか」のようなコピーは論点がずれる。
- 前半と後半で **同じ端末の同じ位置**に別のものを映して対比させる。
- **アドレスバーの URL は前半と後半で別物にする。**前半に notes.rou39.com を出すと
  「Stash Notes がログインを求める」ように見えてしまうので、前半は RFC 2606 の
  予約ドメイン `example.com` を使う。URL が切り替わる瞬間が対比の要。
- **意味のない脈打ちを入れない。**残してあるフラッシュ・パルスは 2 つだけ:
  ✕ を押した瞬間の赤いフラッシュ (拒まれた衝撃) と、文字数が数え終わった瞬間の一発 (届き切った合図)。
  「間が持たないから光らせる」は視聴者には意味が分からないのでやらない。
- **文字自体は動かさない。**ずっと少しずつ拡大すると 1 フレームごとに文字が半端な位置へ
  再描画され、小刻みに震えて見える。移動量は整数 px に丸める。
- **動かすときは速く 大きく。**ゆっくり settle するバネは 1 フレームあたりの変化量が小さく
  「動いていない」ように見える。バネは 16〜18 フレームで終わらせ、
  面積の大きい光の帯・端末ごとの揺れで動かす。

間合いを変えたいときは各シーン冒頭の `T` を触る。フレーム番号で全部書いてある。

## 分析 (`node analyze.mjs`)

書き出した動画を「AI に読ませられる形」に分解する。

```
out/sheet-all.png   全編を 1 秒ごとに並べたコンタクトシート
out/sheet-hook.png  冒頭 5 秒を 0.25 秒ごとに並べたシート
標準出力            絵が止まっている区間の一覧と合計
```

シート画像はそのまま Claude / GPT / Gemini に貼れる。
**静止画を 1 枚ずつ見ても間合いの問題は絶対に見えない。並べると一目で分かる。**

`freezedetect` の閾値 `n` は「どのくらいの変化を動きとみなすか」。
`-60dB` は「技術的にピクセルが変わっているか」、`-50dB` は「人が気づく程度に変わっているか」。
広告として意味があるのは後者なので、このスクリプトは `-50dB` で測っている。

**この数字は目標値ではない。**「4〜5 秒も絵が止まっている区間」を見つけるための道具として使う。
数字を下げること自体を目的にすると、意味のない脈打ちや点滅を足すことになり、
視聴者には何が起きているのか分からない画になる (一度これで失敗した)。

実測の推移:

| 版 | 静止率 | 状態 |
| --- | --- | --- |
| 初版 (30秒) | 76% | 4〜5 秒の死に区間が 3 か所。作り直し |
| 装飾を足した版 | 15% | 数字は良いが意味のない脈打ちだらけ。不採用 |
| 現行 (22秒) | 28〜40% | 意味のない動きを全部外した。**残る静止は 1.6 秒以下**で、
タイトルを読む間・✕ の前のタメ・CTA を読む間など、すべて意図した「間」 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/theme.ts` | 色・フォント・シーンの尺。色は `frontend-notes/src/pages/Landing.tsx` の `--lp-*` (ダーク) と同じ値 |
| `src/doc.ts` | 画面に映すサンプル原稿・文字数・URL・端末サイズ。2 つのシーンで同じものを使う |
| `src/layout.ts` | 縦 / 横 / 正方形の出し分け。短辺 1080 基準なのでサイズは実 px でそのまま書ける |
| `src/anim.ts` | 出現アニメのヘルパ (落ちる・弾む・判子・揺れ) |
| `src/components/Chrome.tsx` | 背景・シーン外枠・字幕・ワードマーク・常時ロゴ・全画面フラッシュ |
| `src/components/Product.tsx` | 画面の中身 (ノート PC / モニタ / 本文 / ログイン画面 / ✕ / バッジ / CTA ボタン) |
| `src/scenes/Title.tsx` | タイトル |
| `src/scenes/Demo.tsx` | 実演。1 枚のキャンバスに 2 台を絶対配置し 消さずに動かす |
| `src/scenes/Words.tsx` | 3 語 |
| `src/scenes/Cta.tsx` | 締め |
| `src/StashNotes.tsx` | 本編 (シーンを並べてクロスフェード) |
| `src/Root.tsx` | 3 比率の Composition 定義 |

尺を変えるときは `src/theme.ts` の `SCENES` だけ触れば 3 比率すべてに反映される。

## 素材についての決めごと

- **絵文字を使わない。**レンダラによって出方が変わるので、アイコンはすべて SVG
  (ランディングと同じ 24x24 / stroke 1.8)。
- **実データを映さない。**秘密 URL も原稿もすべて架空。ログイン画面は特定のサービスを
  模したものではない (ロゴも社名も出さない)。
- **言えないことを言わない。**メモは運営者が読める設計 (E2E 暗号化ではない) なので、
  「誰にも見られない」系のコピーは使わない。
- **無音で完結させる。**SNS はミュート自動再生が大半なので、字幕だけで意味が通るようにしてある。
  BGM を足す場合は編集ソフト側で重ねる (著作権フリー素材を使うこと)。
