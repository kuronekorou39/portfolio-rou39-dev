Intruder Queue は、Burp Suite の Intruder の実行を複数キューに積み、順に流す拡張機能。設定画面には grep の欄があったが、どこにも配線されておらず働いていなかった。v0.5.0 でこれを実装した。

| 変更 | 中身 |
|---|---|
| 判定 | レスポンス全体(ヘッダとボディ)に対して、指定した文字列をそのまま照合する。大文字と小文字は区別する |
| 結果の表 | Grep 列を足し、マッチした文字列をカンマ区切りで並べる |
| 保存と復元 | 結果の JSON に grep の文字列とマッチ結果を含める。項目が無い古いファイルは空として読む |
| 既定値 | 設定画面の grep の既定値を、キューに積むときにジョブへコピーする |

バージョンの直書きが複数箇所に散っていたので、1 か所の定義にまとめた。設定が Burp の再起動をまたいで保存されない点は、UI の注記と README に明記した。README はテンプレートのままだったので、実態に合わせて書き直している。
