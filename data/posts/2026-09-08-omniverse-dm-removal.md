9 月 3 日に入れた DM の見る専画面で、X の会話が「頭だけ」「古いやり取りだけ」しか出なかった。パーサーの不具合ではなく、X の DM が XChat という別の系統に移っていて、旧 API には移行前のメッセージしか残っていなかった。

![X の DM の本文にどこまで近づけたか](/devlog/2026-09-08-omniverse-dm-removal/how-far.svg)

| 分かったこと | 対応 |
|---|---|
| 旧 API で 1 件だった会話が、XChat では 197 件返る | 取得を XChat に切り替え |
| メッセージ本体は JSON ではなく Thrift のバイナリ | 読み取り器を書いた。本文の位置は 3 回取り違えた |
| 本文が読めないものは固定長の鍵と暗号文を持つ。end-to-end の暗号 | 「暗号化されたメッセージ」と表示 |
| ブラウザでは復号済みの本文が画面に出ている | WebView の画面から読もうとした |
| アプリの WebView では PIN の入力画面に飛ばされる | 断念 |

本文は端末の鍵で暗号化され、その鍵は PIN で守られている。読み取り専用の作りで PIN を預かるのは筋が悪いので、扱わないと決めた。X で見られないのに Bluesky だけ見られても意味がないため、DM 機能そのものを取り下げ、関連するコードとテストを削除した。
