---
title: Parallel Stream: 公開を release ブランチに切り出した
summary: push のたびに利用者の画面が変わるのを止めた。Kick は枠の中で配信を選べる
projects: [parallel-stream]
---

UI のページは main から配信していたので、push した時点で公開になっていた。利用者の画面が作業のたびに変わり、版を上げるたびに「拡張機能が古い」が出て、作業途中の ZIP が配られる。

| 変更 | 中身 |
|---|---|
| 公開の切り出し | 配信元を release ブランチにした。URL は変わらない。公開するときだけ release を進める |
| Kick を枠の中で選ぶ | トップの一覧は枠の中でも開けると実測で確認。配信ページへ移ったら、同じ場所・並び順・音量で直接再生の枠に作り直す |
| 復元直後の枠一覧 | 4 枠を復元しても 1 件しか出なかった。復元が終わったところで 1 回描き直す |
| 再読み込み | チャットも読み直す。押す場面はたいていチャットが固まったときのため |

Kick はこれまで、配信ページの URL を貼るしかなかった。他のサイトと同じ「ボタンからサイトを開き、枠の中で選ぶ」流れに揃った。
