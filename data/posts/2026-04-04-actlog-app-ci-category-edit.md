自分で作ったカテゴリは、作ったあとに名前を変えられなかった。作成画面に編集モードを足し、カテゴリ一覧に編集ボタンを置いた。同じ日に GitHub Actions も入れた。

![カテゴリの作成画面を、編集にも使う](/devlog/2026-04-04-actlog-app-ci-category-edit/category-edit.svg)

| 変更 | 中身 |
|---|---|
| カテゴリの編集 | 作成画面を編集にも使う。一覧の編集ボタンから開く |
| メンバーの編集 | 一覧の長押しをやめ、メンバー詳細画面のペンのアイコンから名前を変える |
| ログカードの表示 | メンバーや画像の項目が、生の JSON のままカードに出ていた。リスト型の値はカードに出さない |
| CI | push で解析・テスト・ビルドを走らせる。タグを打つと Android と iOS のリリースビルドを作る |

CI は入れた直後に、起動確認のテストが落ちた。期待する文字列が古かったのと、スプラッシュ画面のタイマーをテストの中で進めていなかったのが原因で、どちらも直した。iOS のビルドは署名が要らないシミュレーター向けに変え、リリースビルドにはアイコンフォントを削らない指定を足した。
