枠の中身は別オリジンの iframe なので、タップは親に届かない。フォーカスの移動で拾っていたが、タッチでは移らないことが多く、枠の縁を狙わないと選べなかった。

![スマホで、枠を選べる範囲](/devlog/2026-08-07-parallel-stream-touch-polish/tap-area.svg)

| 変更 | 中身 |
|---|---|
| タップの通知 | 枠の中の content script が押下ごとに 1 通だけ親へ送る。入れ子のフレームからも中継する |
| ボタンの大きさ | スマホの追加ダイアログのサイトボタンを、約 34px から 48px 前後へ |
| 止まったときの表示 | Twitch の埋め込みが映像の上に出す案内と分類ラベルを隠す。再生ボタンは残す |
| 表示時間 | タッチでの ✕ / ⋮ の表示を 12 秒 → 6 秒 |
| Kick | 映像の上に出たままだったネイティブの操作列を外した |

README は 151 行から 67 行に絞り、詳細を docs/ へ分けた。スクリーンショット 4 枚は、8.3MB の PNG を合計 707KB の JPEG にして載せた。インストール手順は、クローン前提から ZIP に変えた。
