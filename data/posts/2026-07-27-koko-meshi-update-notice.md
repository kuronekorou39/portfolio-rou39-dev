title: ココメシ: 新しい版が出たことをアプリから知らせる
summary: v0.9.0。ストア配布ではないので、更新の知らせをアプリ自身に持たせた
projects: [koko-meshi]
---

Android 版はストアを使わず直接配布している。更新を知らせる役がいないので、利用者は新しい版が出たことを知る手段が無かった。v0.9.0 でアプリ自身に確認させるようにし、あわせて配布まわりを整えた。

| 変更 | 中身 |
|---|---|
| 更新の知らせ | GitHub Releases の最新タグと自分の版を比べ、一覧の上に出す。問い合わせは 12 時間に 1 回だけ。閉じたらその版では出さない |
| 場所検索の失敗 | 上限や通信断でも「0 件」に見えていた。未設定 / 上限 / 拒否 / 通信断を区別して理由を出す |
| API キーの分離 | 地図用と場所検索用にキーを分け、キーごとに使える API を絞れるようにした |
| APK を arm64 のみに | v0.9.0 の APK(41MB)には、端末内 AI が動かない ABI 向けのライブラリまで入っていた |

開発ビルドを配布版と同じアプリに統合する変更も入れたが、実利用しているアプリを開発中のビルドで壊さないために、同じ日に別アプリへ戻した。地図 API のキーの制限と割り当て上限の設定手順は docs に残した。
