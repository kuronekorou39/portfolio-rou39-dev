アカウント一覧のヘッダーにユーザー検索の入口を置いた。どのアカウントの資格情報で探すかを選べる。

![ユーザー検索から表示制限の確認までの画面](/devlog/2026-09-09-omniverse-user-search/search-flow.svg)

| SNS | 検索できる範囲 |
|---|---|
| X | ハンドルの完全一致だけ。名前での検索は別の API が要り、パラメータが未確認なので今回は入れていない |
| Bluesky | ハンドル・表示名・プロフィール文から探す |
| 共通 | @ 付き、プロフィール URL、投稿 URL の貼り付けも受ける。結果をタップするとプロフィールへ |

プロフィール画面からは、X の可視性まわりのフラグを確認する画面を開けるようにした。1 回のリクエストで取れる項目(センシティブ判定、鍵、電話認証の要求など)だけを見る。項目が返らなかったものは「問題なし」ではなく「判定不能」として分ける。自分の資格情報で自分を見ているときは警告を出す。X の可視性フィルタは本人には適用されないので、本人から見て正常でも意味がない。「制限されていないとは言えない」「順位下げは観測できない」ことも、画面に常に出している。

通知のタイプ別フィルタは、リストの頭が色だらけになるので既定で畳んだ。前日に消した DM 機能の残りの定義も削除した。
