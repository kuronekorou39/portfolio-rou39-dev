title: OmniVerse: 自分の DM を、既読をつけずに読む「見る専」画面を足した
summary: 読み取りの GET だけで作り、既読をつける API は一切呼ばない。送信欄も無い
projects: [omniverse]
---

自分のアカウントの DM を、読み取り専用で表示する画面を 2 日で入れた。X も Bluesky も、「既読をつける」のは読み取りとは別の書き込み API になっている。この機能はそれを呼ばないので、開いても相手に既読はつかず、自分の未読も未読のまま残る。

| 項目 | 中身 |
|---|---|
| 取得 | X も Bluesky も GET だけ。テストで「POST を一切呼ばない」ことを検証している |
| 画面 | アカウント詳細から会話一覧、スレッドへ。送信欄は無く、読み取り専用であることを常に表示 |
| 2 日目の追加 | 名前と ID の検索、未読 / リクエスト / グループの絞り込み、アイコンからプロフィールへの遷移、ポスト参照のカード表示 |
| エラーの案内 | Bluesky で DM の権限が無いトークンのときは、エラー本文を画面に出して理由を伝える |

この時点の制限として、X の暗号化された DM(XChat)は対象外。取得できなかったときに切り分けられるよう、失敗時はステータスコードを画面に出している。テストは 1103 件。
