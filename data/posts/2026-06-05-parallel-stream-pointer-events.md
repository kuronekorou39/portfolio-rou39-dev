---
title: Parallel Stream: 枠の操作をタッチ対応にし、透明度と画質調整を足した
summary: ドラッグとリサイズを Pointer Events 化。枠ごとに不透明度と明るさを変えられる
projects: [parallel-stream]
---

枠の移動とリサイズがマウス専用で、タッチやリモートデスクトップ越しでは動かせなかった。操作を Pointer Events に置き換え、あわせて枠ごとの見た目の調整を足した。

| 変更 | 中身 |
|---|---|
| Pointer Events 化 | ポインタを捕捉するので iframe の上でもドラッグが追従する。覆い用のシールドは撤去 |
| 整形モード | ON の間は枠の中身を覆い、どこでも掴んで移動、全 8 辺と角でリサイズ |
| 不透明度 | 選んだ枠を 20〜100% で半透明にする。重ねたとき裏が透ける |
| 画質調整 | 明るさ・コントラスト・彩度を CSS filter で枠ごとに当てる |
| ヘッダの一時表示 | クリックで出し、3 秒後にフェードで消す |

別オリジンの iframe 内のクリックは親に伝わらない。window の blur と activeElement を見て「その枠が押された」を検知している。
