この日は 22 コミット。実機で見つかった不具合を順に潰した。

![ZIP の中の名前と、Android での展開結果](/devlog/2026-08-05-parallel-stream-zip-separator/zip-entries.svg)

| 不具合 | 原因 | 直し方 |
|---|---|---|
| Android で拡張を読み込めない | Compress-Archive がパス区切りに \ を書き、フォルダ名ごと 1 つのファイル名として展開された | 中身を平置きに戻し、リリース時に ZIP を開いて検査する |
| 縦積みでチャットが映像を覆う | CSS の詳細度で負け、iframe がタイル基準で配置されていた | セレクタの詳細度を上げた |
| スマホで YouTube のチャットが出ない | スマホ版の HTML が返り、チャットの情報を見つけられなかった | PC 版を要求し、決め打ちせず全体を探す |
| 枠を足すたびに一瞬大音量で鳴る | 音量を当てる経路が 1 秒ごとのポーリングだけだった | 再生開始などの契機で即時に当てる |

軽量 / 通常の切替は UI から外し、映しているもので自動的に決めるようにした。既定の実音量は 5%。弾幕とチャットの全体設定を ≡ メニューに足し、チャットは既定で畳む。
