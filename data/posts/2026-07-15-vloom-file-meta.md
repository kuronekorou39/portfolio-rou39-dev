---
title: Vloom: 受信したファイルに元の名前と種別が残るようにした
summary: 送信データの先頭にファイル名と MIME を付ける。docx が zip になる問題も解消
projects: [vloom]
---

vcode は生のバイト列しか運ばないので、受信側はファイル名を時刻から作り、種別を中身から推測していた。元の名前は失われ、中身が ZIP の docx / xlsx / pptx は zip と判定されていた。

| 変更 | 中身 |
|---|---|
| 自己記述ヘッダ | 送信データの先頭にファイル名と MIME を付ける。アプリと PWA の全経路で対応 |
| 後方互換 | ヘッダの無い旧データは、従来の推測と時刻の名前に落ちる |
| 共有時の名前 | 内部の ID 名のまま渡していて、共有先で番号の名前になっていた。元の名前でコピーしてから渡す |
| 端末に保存 | OS の保存ダイアログを開くボタンを追加。初期値は元の名前 |

大きいファイルでカバレッジ格子が伸びてカメラ表示を押し上げていたのも、格子を固定の高さ (72px) にして直した。
