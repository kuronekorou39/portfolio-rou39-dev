5 月 21 日以来の更新。リリースまわりを整え、入っている版と、新しい版が出ているかをアプリから確認できるようにした。

![版がタグからアプリに入り、Releases と見比べる流れ](/devlog/2026-08-12-easy-blur-release-prep/version-flow.svg)

| 変更 | 中身 |
|---|---|
| バージョン表示と更新確認 | ホーム画面に版を出す。GitHub Releases を見て、更新があればリンクを出す |
| アプリアイコン | ホーム画面と同じデザインで生成した。Android のアダプティブ / モノクロにも対応 |
| 表示名 | アプリの表示名を「Easy Blur」に修正 |
| 版の管理 | 設定ファイルの版をタグと揃え(0.7.0)、CI でタグから版を注入する |
| README | インストールとリリースの手順を書いた |

「プロ仕様の」のような自称の文言はアプリから削った。

非推奨になった並べ替えの API を新しいものへ移したところ、CI の Flutter が古くてその API が無く、リリースビルドが失敗した。CI の Flutter を手元と同じ版に上げて解消した。
