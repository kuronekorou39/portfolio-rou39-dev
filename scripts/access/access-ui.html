アクセス解析

CloudFront のアクセスログ(S3)を集計するローカル専用ツール
「更新」で読み込みます(ログの取得と解凍に少しかかります)。
ページ表示は「HTML が返ったリクエスト」で数えています(アセットと API は除外)。
SPA は存在しないパスにも 200 とトップページを返すため、実在するルートに一致しないものは「探索アクセス」として分離し、日別・訪問者・リファラからは除いています。
SPA の内部遷移はリクエストが飛ばないためログに残りません。パス別は「入口ページ」(直接アクセス・再読み込み・クローラ)の内訳です。
IP と User-Agent はアクセス元の確認用に表示しています(このローカル画面のみ。ログ自体は 90 日で自動削除)。
ログ配信には数分〜数時間の遅れがあります。時刻はすべて JST。
